# Проверки сборки Frontier Corp

Проект импортирован и экспортирован в Godot 4.6.3. Windows-комплект рассчитан на x64. Для оконных проверок в Linux использовались Wine, OpenGL Compatibility и программный рендерер Mesa llvmpipe.

## Островной режим

Windows-сборка под Wine и проект в Godot прошли 55 проверок. Новая игра создала 64 клетки и два дерева. Покупка 336 клеток расширила остров с 8×8 до 20×20. Отдельно проверены старое сохранение 5×5, его цены и покупка земли на удалённых координатах.

Тест проверил загрузку всех семи MP3, стартовые рецепты печи и конструктора, открытие винтов исследованием и перенос монумента с его хранилищем. Проверены цена в режиме покупки, изменение размера содержимого инвентаря при растягивании, отмена и подтверждение удаления залежи.

Для 300 контейнеров проверены все девять возможных материалов, от одного до трёх видов и от одной до трёх единиц каждого. Отдельно проверены появление за камерой, интервал 300 секунд, остановка о берег, качка, ловля рыбы, прыжок из воды, огонь под навесом и смыв берегового слоя.

Повторить проверку из папки проекта можно командой `godot --headless --audio-driver Dummy -- --test=ocean --seed=421 --size=128`. Стартовый остров снят в игровом движке. [Кадр из игры](../previews/ocean-island.jpg)

## Нагрузочный замер

Оконный тест на Mesa llvmpipe, OpenGL Compatibility, профиль Low при 1280×720. Среда ограничена двумя вычислительными ядрами, аппаратная видеокарта отсутствует. В таблице указано время обработки и вывода целого кадра.

| Сцена | Постройки | Враги | Средний кадр | Худший кадр | Вызовы отрисовки | Примитивы |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Высадка, карта 1152×1152 | 2 | 0 | 1004.98 мс | 1107.7 мс | 601 | 5344051 |
| Нагрузочная колония, карта 256×256 | 1340 | 81 | 1779.47 мс | 3320.2 мс | 755 | 4930484 |

Ближние модели используют исходную для этой поставки геометрию. Вдали движок переключает индексные сетки, в том числе для отдельных материалов. Тяжёлая растительность сгруппирована по участкам 24 м. На неподвижной камере мир прекращает повторный обход уже подготовленных участков. Замеры на игровой видеокарте и длительная сессия на Lenovo Xiaoxin 16 Pro остаются открытыми. Для локального замера в папке Windows есть Benchmark.cmd.


## Воспроизведение из исходников

Команды выполняются в папке с project.godot после импорта проекта. Для двух проверок подвижной геометрии и проверки дальности используется оконный рендерер.

```sh
godot --headless --editor --import
godot --headless res://tools/qa/colony_check.tscn -- --size=128
godot --headless res://tools/qa/exploration_check.tscn -- --size=128
godot --headless res://tools/qa/geology_check.tscn -- --size=128
godot --headless res://tools/qa/revision_check.tscn
godot --headless res://tools/qa/avatar_check.tscn
godot --headless res://tools/qa/rig_check.tscn
godot --rendering-method gl_compatibility res://tools/qa/socket_check.tscn
godot --rendering-method gl_compatibility res://tools/qa/turret_check.tscn
godot --rendering-method gl_compatibility res://tools/qa/machine_check.tscn
godot --rendering-method gl_compatibility res://tools/qa/distance_check.tscn
godot --rendering-method gl_compatibility --resolution 1280x800 res://tools/qa/landscape_view.tscn -- --size=128 --summer
```
